# Черновик CheckSafety

`CheckSafety.srv` сохранён как заготовка интерфейса. Ранее файл копировался
через `setup.py`, но Python-класс сервиса не генерировался, а обработчик
не возвращал ответ. Узел STT поэтому импортировал отсутствующий `lwitch.srv`.

Сейчас фильтрация работает через подписку на `/stt_output`. Черновик сервиса
не устанавливается и не импортируется рабочими узлами.

Если сервис понадобится, его следует реализовать в отдельном ROS-пакете
интерфейсов с генерацией через `ament_cmake`, затем подключить клиент и
обработчик. См. [официальную документацию ROS 2](https://docs.ros.org/en/rolling/Tutorials/Beginner-Client-Libraries/Custom-ROS2-Interfaces.html).
